# Analysis Code for [A human blood-brain barrier model reveals distinct effects of pericytes on brain metastatic transmigration]
This repository contains the custom Fiji macros and R scripts used for image analysis and quantitative measurements in this study.

## 1. Junction Fluorescence Quantification
Scripts for quantifying VE-cadherin and β-catenin fluorescence intensity at cell junctions using Fiji and R.

## 2. Brain Metastasis Quantification
Fiji macro for automated quantification of metastatic tumor volume in whole-brain images acquired using light-sheet fluorescence microscopy.

## Requirements
- Fiji (ImageJ)
- R (base R; no additional packages required)

## Usage
Please refer to the individual scripts and their comments for analysis procedures and execution instructions.
